# 提示词示例

[English](./EXAMPLE_PROMPTS.md) | 简体中文

以下示例展示了如何提示 LLM 使用 Telnet 工具。请仅连接你拥有或获明确授权访问的服务，并遵守其使用规则。

**安全提示：** 不要在提示词中包含密码或其他凭据。使用云端 LLM 时，应由你通过安全的带外通道自行完成登录。Telnet 默认不加密，请勿通过未加密连接发送敏感信息。

## 连接 MUD 并探索

```text
连接到我有权访问的 MUD（主机 mud.example.com，端口 4000），以访客身份帮我探索。我以前没玩过 MUD，请解释基本命令和屏幕上的内容。
```

Claude 会先设置客户端身份，然后连接并引导你探索 MUD 环境。

## MUD 游戏体验

```text
帮我体验一个我有权访问的 MUD：

1. 连接到 mud.example.com 的 4000 端口
2. 如果服务器要求输入名称，请使用“Guest”
3. 帮我探索新手区域并学习基本命令
4. 解释战斗系统的基本规则
5. 命令之间等待 2 到 3 秒，避免发送过快
6. 启用连续模式，让交互更连贯

我玩过桌上角色扮演游戏，但没玩过 MUD。请边玩边解释，我可以先尝试什么？
```

## 角色创建与记忆

```text
帮我在我有权访问的 MUD 上创建一个角色：

1. 连接到 mud.example.com 的 4000 端口
2. 引导我完成角色创建
3. 将角色设定保存到此连接的记忆中
4. 带我探索新手区域
5. 在游戏过程中解释基本机制

我想创建一个偏重智力的施法者角色。
```

## 检查获授权管理的旧式系统

```text
我需要检查一台由我负责管理、且只支持 Telnet 的旧式监控系统。请：

1. 连接到我已获授权的测试主机 monitor.example.com 的 2323 端口
2. 不要尝试猜测、索取或在提示词中输入凭据；如果需要登录，请暂停并提示我通过安全的带外通道自行完成
3. 登录完成后，只运行我明确指定的只读状态检查命令
4. 总结输出中的错误和警告；不要读取、复制或保存凭据及敏感配置

该系统使用专有命令语法；遇到不确定的命令时先向我确认。
```

## MUD 连接模板

```text
连接到我有权访问的 [MUD 名称]（主机 [主机名]，端口 [端口]），并帮我：

1. 以访客身份登录；如需凭据，请暂停并让我通过安全的带外通道自行输入
2. 使用基本命令探索环境
3. 启用连续模式
4. 每条命令后等待 [X] 秒
5. 将重要信息保存在此连接的记忆中

我想要 [具体目标或体验]。
```

## 远程系统维护模板

```text
我需要通过 Telnet 管理一台由我负责、且已获明确授权的旧式 [系统类型]。请：

1. 连接到 [已获授权的主机] 的 [端口]
2. 如果需要登录，请暂停，让我通过安全的带外通道自行完成；不要索取或发送密码
3. 仅运行以下已确认安全且只读的诊断命令：
   - [命令 1]
   - [命令 2]
4. 总结输出中的错误或警告
5. 不要输出或保存凭据、个人信息或敏感配置

该系统使用 [具体说明] 命令语法。
```

## 本地邮件服务器示例

```text
我正在排查本机邮件服务器的问题。请连接到 localhost 的 [经确认的测试端口]，并仅执行非破坏性的能力查询：

1. 发送 EHLO mycomputer.local
2. 发送 HELP
3. 总结服务器返回的扩展能力和错误信息
4. 如需检查 STARTTLS，请只说明返回结果；不要发送凭据或邮件内容
```
