# 提示词示例

[English](./EXAMPLE_PROMPTS.md) | 简体中文

以下示例展示了如何提示 LLM 使用 MCP-Telnet 连接和操作基于文本的 Telnet 服务。示例中的主机和地址仅供说明；请替换为你拥有或获明确授权访问的服务，并遵守其使用规则。

**安全提示：** 不要在提示词中包含密码或其他凭据。使用云端 LLM 时，如需登录，请暂停操作并通过安全的带外通道自行输入凭据。普通 Telnet 通信不加密，不要通过未加密连接发送敏感信息。

## 查看服务状态

```text
连接到我有权管理的监控设备 monitor.example.net:2323。先读取服务端欢迎信息；如果需要身份验证，请暂停并提示我通过安全的带外通道自行登录。登录后只执行只读状态检查，概述设备状态和告警，不要更改配置。
```

## 等待指定响应后继续

```text
连接到我有权访问的文本服务 text-service.example.net:2323。发送 status 命令，并使用 waitFor 等待响应中的“Status:”或命令提示符“>”。收到响应后，帮我总结状态；如果超时或没有匹配到内容，请说明实际收到的输出，不要重复发送命令。
```

## 分步检查网络设备

```text
请检查我负责管理的测试交换机 192.0.2.10:23：

1. 如需登录，暂停并让我通过安全的带外通道输入凭据；不要索取或输出凭据
2. 先运行只读命令 show interfaces status，汇总端口状态
3. 再运行只读命令 show alerts，概述当前告警
4. 不要显示完整配置、修改设备设置或执行重启等操作
5. 将不含凭据和敏感配置的检查结论保存到此连接的记忆中

如果设备命令语法与上述命令不同，请先询问我，不要猜测命令。
```

## 调试本地文本协议服务

```text
帮我检查本机运行的 SMTP 测试服务。连接 localhost 的 2525 端口，只执行非破坏性的协议能力查询：

1. 发送 EHLO mycomputer.local
2. 总结服务端返回的能力和错误信息
3. 如需检查 STARTTLS，只报告服务端是否声明支持
4. 不要发送邮件、收件人地址、凭据或其他敏感内容
```

## 保存连接备注并查看日志

```text
连接到我有权管理的服务 monitor.example.net:2323，并在不保存凭据或敏感信息的前提下：

1. 查询该连接已有的记忆和会话日志
2. 完成我指定的只读状态检查
3. 将设备名称、非敏感检查结果和后续待办事项保存到该连接的记忆中
4. 不要将日志中的凭据或敏感配置复制到记忆或回复中
```

## 通用 Telnet 服务模板

```text
连接到我拥有或获明确授权访问的 [服务名称]（主机 [主机名]，端口 [端口]），并按以下要求操作：

1. 先读取服务端初始输出，判断服务类型和当前提示
2. 如果需要登录，暂停并让我通过安全的带外通道自行输入凭据
3. 仅执行我明确指定且已确认安全的命令：[命令列表]
4. 每条命令后等待 [等待时间] 秒，或使用 waitFor 等待 [预期响应模式]
5. 总结响应；除非我明确要求并确认，否则不要更改服务端状态
6. 不要保存或复述凭据、个人信息及敏感配置

遇到未知命令或无法判断操作影响时，请先向我确认。
```
