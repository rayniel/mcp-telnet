# 更新日志

[English](./CHANGELOG.md) | 简体中文

## 0.5.0（当前）

- 为 `send_command` 增加 `waitFor` 参数，支持按模式等待响应
  - 轮询响应缓冲区以匹配正则表达式，而不是使用固定等待时间
  - 匹配到预期输出后立即返回，显著减少等待时间
  - 超时后返回已收集的内容
  - 不区分大小写，并支持完整的正则表达式语法
- 为 `sequence_commands` 增加 `waitFor` 支持，可为每条命令单独设置模式等待
  - 序列中的每条命令均可分别使用 `waitFor` 或 `waitAfter`
  - 支持在一次工具调用中完成多步交互（例如购买流程或菜单导航）
- 在连接层新增内部函数 `sendCommandWaitFor()`
